# 📉 Transaction Monitoring & Performance Dashboard (Excel)

## 🔍 Overview

Interactive Excel dashboard analyzing 500+ transaction records to monitor financial performance using KPIs, Pivot Tables, and visualizations.

---

## 🎯 Objective

To create a dashboard for tracking transaction performance, revenue trends, and success rates using Excel-based tools.

---

## ⚙️ Key Features

* Interactive dashboard with Pivot Tables and Pivot Charts
* Slicers for dynamic filtering
* KPI cards displaying key metrics
* Visual representation of transaction performance

---

## 📊 Key Metrics

* Total Transactions: 500+
* Revenue: ₹15.7L+
* Success Rate: 87%+
* High-Value Transactions tracking

---

## 🔑 Excel Skills Used

* Pivot Tables
* Pivot Charts
* Slicers
* KPI calculations
* Data analysis and visualization

---

## 💼 Business Value

* Enables quick performance monitoring
* Provides insights into transaction trends
* Helps identify high-value and successful transactions
* Supports data-driven decision making
