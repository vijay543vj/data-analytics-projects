# 📊 Data Analytics Portfolio

This repository contains a collection of end-to-end data analytics projects demonstrating skills in **SQL, Power BI, and Excel** for reporting, dashboarding, and risk analysis.

---

## 🔍 Projects Overview

### 1. MIS Reporting System (MySQL)

- Built an automated MIS reporting system for a merchant network
- Processed **12,000+ transactions** across **120+ merchants**
- Generated insights on revenue, disputes, SLA compliance, and merchant performance

---

### 2. Credit Card Risk Flagging System (MySQL)

- Developed a rule-based transaction monitoring system
- Implemented 5 fraud detection rules (anomaly, velocity, failure, etc.)
- Identified high-risk transactions, customers, and merchants

---

### 3. Merchant Performance Dashboard (Power BI)

- Designed an interactive dashboard for transaction and risk analysis
- Tracked KPIs such as revenue, success rate, and dispute rate
- Enabled drill-down analysis using slicers and visualizations

---

### 4. Excel Automation & Financial Data Analysis

- Built a multi-sheet system for automated billing and EMI calculations
- Used advanced formulas for dynamic data processing
- Created MIS-style reporting outputs

---

### 5. Transaction Monitoring Dashboard (Excel)

- Designed an interactive dashboard analyzing 500+ transactions
- Used Pivot Tables, Charts, and Slicers for performance tracking
- Built KPI cards for revenue, success rate, and transaction metrics

---
